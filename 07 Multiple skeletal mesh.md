# 07 Multiple skeletal mesh

The Add Additional Fire VFX function allows you to quickly bind fire effects to multiple Skeletal Mesh components and Niagara Systems at once.

It ensures all additional meshes and particles are connected to the CharacterFireVFX component and inherit the same global controls, keeping fire behavior, parameters, and timing synchronized across the entire character setup.
